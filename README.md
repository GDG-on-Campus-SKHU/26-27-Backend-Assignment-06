# AWS EC2 배포

## 과제 요구사항

1. AWS EC2에 Spring Boot 프로젝트를 배포합니다.
2. 그동안 자신이 과제로 구현했던 Spring Boot 프로젝트 중 하나를 선택하여 배포합니다.
3. 애플리케이션 실행에 필요한 Java, 데이터베이스 등의 환경을 구성합니다.
4. 도메인을 연결하고 Nginx 리버스 프록시를 설정합니다.
5. HTTPS를 적용합니다.
6. Postman으로 배포된 서버의 서로 다른 API 2개 이상을 호출하여 정상 응답을 확인합니다.

> [!NOTE]
> 배포 방식은 자유롭게 선택할 수 있습니다.
> 단, **도메인 연결, Nginx 리버스 프록시 설정, HTTPS 적용은 필수**입니다.

---

## 제출 형식

1. 과제 레포를 fork합니다.
2. fork한 개인 레포를 `git clone`하여 파일을 불러옵니다.
3. 자신의 영문 이름으로 된 폴더를 생성합니다. (ex. `parkyeonji`)
4. 이름 폴더 아래에 다음 폴더를 생성하고 결과물을 첨부합니다.
    - `[본인 스프링부트 프로젝트 이름]`: 배포에 사용한 Spring Boot 프로젝트 소스 코드
    - `Postman`: 배포된 서버의 API 호출 성공 화면 스크린샷 **2장 이상**
5. 과제 레포로 PR을 날립니다.

> [!WARNING]
> 소스코드 제출 시 `.env`, 데이터베이스 비밀번호, API 키, AWS 인증 정보 등 민감한 정보가 포함되지 않도록 주의해 주세요.
